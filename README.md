# Chat App

A real-time chat application built with React, Chakra UI, Node.js, Express, MongoDB, Socket.io, and Redis.

## Live 
- https://chat-app-s89y.onrender.com/

## Features

- User authentication with login and signup
- Real-time one-to-one and group chat
- Online user presence
- Message notifications
- Seeded demo content for faster QA and presentation

## Tech Stack

- Frontend: React, Chakra UI, Socket.io client
- Backend: Node.js, Express, Socket.io
- Database: MongoDB
- Cache and presence: Redis

## Run Locally

1. Install dependencies:

   ```bash
   npm install
   cd frontend
   npm install
   cd ..
   ```

2. Start the backend:

   ```bash
   npm start
   ```

3. Start the frontend in a separate terminal:

   ```bash
   cd frontend
   npm start
   ```

4. Seed demo data if needed:

   ```bash
   npm run seed
   ```
